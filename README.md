# 🎬 ScreenMatch - Movies & Series Catalog

🌐 **Languages / Idiomas:** 
[English](#-english) | [Português](#-português)

---

## 🇺🇸 English

**ScreenMatch** is a Java application built to demonstrate Object-Oriented Programming (OOP) principles and integration with external REST APIs.

### 🚀 Features
* **Data Modeling:** Object structures representing movies, series, and episodes using inheritance and encapsulation.
* **API Integration:** Consuming real-time movie data from the [OMDb API](http://www.omdbapi.com/).
* **Data Parsing:** Deserializing JSON API responses into Java objects using the `Gson` library.
* **Error Handling:** Input validation and HTTP request exception handling.

### 💻 Tech Stack & Tools
* **Language:** Java (JDK 17+)
* **Version Control:** Git & GitHub (branch management and structured commits)
* **Concepts:** Object-Oriented Programming (OOP), Records, Custom Exceptions
* **Technical Resources:** `HttpClient`, `HttpRequest`, `HttpResponse`, Gson library

## 🇧🇷 Português

O **ScreenMatch** é uma aplicação desenvolvida em Java focada na aplicação prática dos pilares da Programação Orientada a Objetos (POO) e no consumo de serviços web externos via API REST.

### 🚀 Funcionalidades
* **Modelagem de Dados:** Estruturação de classes para representação de filmes, séries e episódios com encapsulamento e herança.
* **Consumo de API:** Integração com a [OMDb API](http://www.omdbapi.com/) para busca dinâmica de títulos em tempo real.
* **Parse de Dados:** Conversão de dados em formato JSON para objetos Java utilizando a biblioteca `Gson`.
* **Tratamento de Exceções:** Validação de entradas e manipulação de erros em requisições HTTP.

### 💻 Tecnologias & Ferramentas
* **Linguagem:** Java (JDK 17+)
* **Versionamento de Código:** Git & GitHub (gerenciamento de branches e commits estruturados)
* **Conceitos:** Programação Orientada a Objetos (POO), Records, Tratamento de Exceções
* **Recursos Técnicos:** `HttpClient`, `HttpRequest`, `HttpResponse`, Biblioteca Gson
